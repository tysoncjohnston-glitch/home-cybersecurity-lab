# Uptime Kuma

## Purpose

Uptime Kuma is used for monitoring infrastructure availability, service uptime, and operational visibility across the lab environment.

The platform performs automated health checks against internal services and network resources.

---

# Monitoring Functions

Current monitoring includes:
- Internet connectivity
- Internal service availability
- Reverse proxy availability
- Portainer accessibility
- Authentik availability

Monitoring intervals and retry behavior were configured to provide visibility into outages and service interruptions.

---

# Security and Infrastructure Concepts

The deployment provided hands-on experience with:
- Service monitoring
- Availability management
- HTTP/HTTPS monitoring
- Reverse proxy awareness
- Trust proxy configuration
- Operational visibility
- Alerting concepts

---

# Key Lessons Learned

- Difference between HTTP and HTTPS monitoring behavior
- Impact of self-signed certificates on monitoring
- Importance of proxy trust settings behind reverse proxies
- Service validation after updates and reboots
- Operational importance of monitoring and visibility
