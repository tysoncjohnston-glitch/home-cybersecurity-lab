# Authentik

## Purpose

Authentik serves as the centralized identity and access management platform for the lab environment.

It provides:
- User authentication
- MFA enforcement
- OAuth/OIDC identity provider functionality
- Centralized access control


# Implemented Features

Implemented functionality includes:
- TOTP MFA
- User and group management
- OAuth/OIDC provider configuration
- Application integration
- Federated authentication workflows

Authentik was integrated with Portainer to centralize authentication and enforce MFA protected administrative access.


# Security Concepts Practiced

- Identity and Access Management (IAM)
- MFA implementation
- OAuth/OIDC authentication
- Authentication vs authorization
- User provisioning
- Access control
- Centralized identity management
- Administrative security controls


# Key Lessons Learned

- MFA workflow implementation
- OAuth redirect URI security considerations
- Relationship between identity providers and service providers
